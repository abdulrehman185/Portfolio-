Portfolio deployment

1. Upload this folder's contents to the root of your GitHub repository.
2. Ensure the main file is named index.html.
3. Import the GitHub repository into Vercel.
4. For a static HTML site, use the Other framework preset and leave Build Command and Output Directory empty (or use the repository root as the output directory if prompted).
5. Deploy.

The CV PDF is embedded inside index.html, so no separate CV file is required.
